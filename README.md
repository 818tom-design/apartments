# Apartment Finder

Self-contained interactive dashboard of apartment listings (Ramat Gan, Givatayim, Rishon LeZion, Holon, Bat Yam).
Open `index.html` in any browser, or view via GitHub Pages.

## Penalty Rush

`penalty.html` — a free-to-play penalty shootout game (virtual coins only). Pick a target zone with its own payout multiplier, set your bet, and kick — or switch to Keeper mode and pick where to dive. Includes streak bonuses, animated canvas stadium graphics, sound effects, and a free-coin top-up when you run out.

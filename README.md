# Apartment Finder

Self-contained interactive dashboard of apartment listings (Ramat Gan, Givatayim, Rishon LeZion, Holon, Bat Yam).
Open `index.html` in any browser, or view via GitHub Pages.

## Penalty Rush

`penalty.html` — a free-to-play penalty game (virtual coins only), played from the goalkeeper's point of view. The striker faces you from the penalty spot; you choose one of four corners to dive (top/bottom × left/right, each with its own payout multiplier), set your bet, and dive — guess right and you save it for the multiplier. Includes streak bonuses, first-person glove animations, canvas stadium graphics, sound effects, and a free-coin top-up when you run out.
